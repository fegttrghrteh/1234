# Практическая работа №2

## Запуск тестов

```bash
node tests.js
```

## Что нужно заполнить

Откройте `student-template.js` и заполните участки `TODO`.

Не изменяйте:

- названия функций;
- список параметров функций;
- блок `module.exports` в конце файла.

Тесты проверяют результат работы функций. Условия задач и примеры находятся в документе `Практическая_работа_2.docx`.

## Сдача

В репозитории должны находиться:

- `student-template.js`;
- этот README или собственная краткая инструкция;
- при выполнении браузерного варианта — HTML/JS-файлы с вводом через `prompt()` / `confirm()` и выводом через `alert()` или `console.log()`.

Перед отправкой обязательно выполните:

```bash
node tests.js
```

Все группы тестов должны завершиться успешно.
